VETER v1.2.3 — исходники Geode-мода
Цель сборки: Geometry Dash 2.2 / Geode SDK 5.11.2, Android32 и Android64 через GitHub Actions.
> Это архив исходников, а не готовый `.geode`-файл. В этой среде нет установленного Geode SDK, поэтому компиляцию здесь подтвердить нельзя. Архив проверяется на целостность и корректность JSON; перед установкой обязательно проверь GitHub Actions.

Изменения v1.2.0
Исправлена привязка текущего буфера GD Bot к слоту: старый макрос нельзя случайно сохранить в другой слот.
Завершение обычного воспроизведения перенесено после последнего обновления физики: конечное нажатие не отпускается раньше времени, а `BOT LOOP` сбрасывает уровень только после завершённого кадра.
`BOT PLAY` при несовпадении выбранного и загруженного слотов сначала загружает выбранный макрос; если в нём нет валидной записи, старый буфер не запускается.
`BOT REC`, `BOT LOAD` и `BOT PLAY` блокируются во время несовместимого активного действия, чтобы не потерять запись из-за случайного нажатия.
Переключение слота запрещено во время записи/воспроизведения/Continue. `BOT STATUS` показывает выбранный слот и слот, которому принадлежит буфер.
Существующий формат `GDBOT1` сохранён, старые макросы остаются совместимыми.
Изменения v1.1.9
`BOT LOOP` теперь перезапускает уровень с начала каждого цикла, а не накладывает следующий проход на состояние у финиша предыдущего.
При включённом `Auto-Retry` смерть во время `BOT PLAY` или воспроизведения `CONTINUE` сбрасывает таймер и индекс макроса, после чего бот повторяет запись с начала.
Если бот погибает во время обычной записи, запись корректно останавливается: формат макроса пока не кодирует события смерти и перезапуска. Если смерть происходит в добавочной части Continue, неполный хвост отбрасывается и сохраняется исходный макрос — так следующий Continue снова начнётся с рабочего старого маршрута.
Скорость таймера не добавляет лишний кадр после сброса/повтора макроса.
Изменения v1.1.8
Добавлена кнопка `CONTINUE`: воспроизводит сохранённый макрос с начала в Practice Mode, затем переходит к записи новых событий в тот же список, не очищая старые.
`CONTINUE` автоматически включает Practice Mode и перезапускает уровень с начала; после достижения конца макроса создаёт чекпоинт в точке продолжения, если игра позволяет его создать.
На границе старой записи бот отпускает удерживаемые кнопки и добавляет эти release-события в объединённый макрос.
Продолженная запись автоматически сохраняется при нажатии `BOT STOP`, при выходе/смене уровня и при переключении на новую запись/загрузку (если сохранение не удаётся, предыдущий файл не заменяется).
При воспроизведении Continue ручные игровые нажатия блокируются, чтобы не менять маршрут до конца старого макроса.
Для входа с главного меню сначала требуется открыть тот же уровень: PlayLayer отсутствует вне уровня, поэтому режим практики нельзя включить до входа в геймплей.
Изменения v1.1.7
Исправлена согласованность номера версии в `mod.json`, `CMakeLists.txt`, README и журнале загрузки.
GD Bot проверяет макрос перед сохранением: временные метки должны быть конечными, неотрицательными, упорядоченными и не длиннее 24 часов.
Сохранение GD Bot сначала записывает временный файл и только после успешной записи заменяет слот, чтобы не обрезать предыдущую запись при прерывании сохранения.
При загрузке отсутствующего или повреждённого слота предыдущий макрос в памяти сохраняется; новая запись заменяет его только после полной проверки файла.
Формат `GDBOT1` и имя первого слота `gdbot.gdm` оставлены для совместимости.
> Эти изменения прошли статические проверки исходников и файлов. Android32/Android64 сборка и поведение в игре требуют проверки GitHub Actions.
Изменения v1.2.1
Переделано основное меню: более компактная сетка, элементы помещаются в меньшую высоту окна.
Убран текстовый ярлык MSP с плавающей кнопки; используется иконка VETER из resources/icon.png с текстовым запасным вариантом.
Для панели добавлен тёмный фон и неоновый акцент.
Основное меню
Noclip — не завершать попытку смертью от столкновения; вместе с режимом есть индикатор лучшего процента и числа столкновений.
Speedhack — множитель от 0,1× до 5× с шагом 0,1×.
Music — остановка/возобновление музыки.
Music Speed Sync — масштабирует pitch музыкального канала уровня под Speedhack и старается сохранять изменения pitch, которые задаёт сама игра. Зависит от активного музыкального канала и всё ещё требует проверки на Android32/Android64.
GD Bot — запись ввода, сохранение/загрузка локального макроса, воспроизведение и `CONTINUE` (Practice replay → checkpoint → append recording). Воспроизведение привязано к уровню и освобождает удерживаемые кнопки; при включённом Auto-Retry перезапускает макрос после смерти, а BOT LOOP начинает каждый проход с начала уровня. Тайминги и совместимость с разными режимами игры всё ещё требуют проверки.
MORE TOOLS
FPS Bypass и изменение желаемого FPS (60–360, шаг 30). Реальные кадры ограничены дисплеем/устройством.
Auto-Retry, Fast Reset, Confirm Exit.
Show Hitboxes, Show Hitboxes on Death, No Death Effect.
Practice Music — переключение встроенного поведения музыки практики.
Noclip Limit — число игнорируемых столкновений до восстановления обычной смерти.
Frame Step — экспериментальная блокировка обновления игрового слоя до нажатия `STEP +1`; это не полноценный детерминированный симулятор по одному физическому шагу.
CP PREV / CP NEXT — переход по уже созданным чекпоинтам Practice Mode; это не переключатель Startpos-объектов редактора.
Layout Grid — полупрозрачная экранная сетка 32 px.
VISUALS
Position Trail — показывает недавнюю пройденную линию движения.
Trajectory Prediction — приблизительно продолжает последние смещения игрока пунктиром на 14 шагов вперёд. Это экстраполяция, не физический симулятор: порталы, столкновения, триггеры, смена гравитации и игровых режимов могут изменить путь.
Show Clicks и CPS counter.
Game FPS Counter — отображает частоту вызовов игрового слоя за скользящее полусекундное окно. Это игровая частота обновления, а не гарантия физической частоты вывода экрана.
Transparent Pause — снижает непрозрачность части элементов окна паузы при его открытии.
Hide Pause Button — скрывает найденную кнопку паузы в уровне. При включении убедись, что знаешь, как открыть меню модификации/вернуть переключатель.
Custom Menu Music — опциональная замена музыки главного меню; стандартный `menuLoop.mp3` восстанавливается после выключения функции и возврата в меню.
Как подключить собственную музыку
Открой папку сохранения мода VETER в Geode.
Скопируй туда MP3-файл с точным именем `custom-menu.mp3`.
В главном меню открой `MORE TOOLS` → `VISUALS` → `CUSTOM MUSIC ON`.
Музыка применяется только в меню, не во время уровня.
UNLOCKS — ограничения
Есть локальные переопределения некоторых проверок: Unlock All, Icon Kit, Main Levels, Shop, Vault и Text Length. Это не выдаёт валюту, не меняет серверные данные и не гарантирует обход всех проверок покупки/доступа. Некоторые экраны игры используют дополнительные условия.
EDITOR
При выбранных объектах работают:
X− / X+ и Y− / Y+ — свободное перемещение выделения с шагом `0.1`, `1` или `10`;
ABSOLUTE X/Y — поля числовых координат, которые устанавливают выбранным объектам указанную абсолютную позицию;
COPY TRANSFORM / PASTE TRANSFORM — сохранить позицию, поворот и масштаб первого выделенного объекта, затем применить их к каждому выбранному объекту;
ROT ±15° и ROT ±90°;
SCALE ±0.1.
Это вспомогательная панель выбранных объектов; изменения координат/масштаба/поворота нужно сохранить обычным способом в редакторе. COPY TRANSFORM хранится в настройках мода и доступен после перехода между уровнями.
Что из списка Mega Hack пока не реализовано полностью
Не выдаю эти пункты за работающие функции: Startpos Switcher по Startpos-объектам, Smart Startpos, полноценную физическую симуляцию будущей траектории, настоящий Object Limit Bypass, Zoom Bypass редактора, Verify Bypass публикации, Copy Hack для защищённых онлайн-уровней, скрытие всего меню паузы и Auto-Hide Cursor (неактуален для Android без отдельной платформенной реализации). Main Levels/Shop/Vault/Unlocks — именно локальные проверки, а не постоянные разблокировки.

GD Bot
`BOT LOOP ON/OFF` включает повтор макроса по кругу. Удерживаемые кнопки отпускаются на границе каждого прохода.
`-0.25x` / `+0.25x` регулируют скорость воспроизведения от 0,25× до 2,00×.
`BOT SLOT 1/2/3` переключает слот записи; `BOT SAVE` и `BOT LOAD` работают с активным слотом. Слот 1 использует старый файл `gdbot.gdm`; слоты 2 и 3 используют отдельные файлы.
Открой нужный уровень.
Нажми `BOT REC` и пройди участок.
Нажми `BOT SAVE`.
Для повтора используй `BOT LOAD`, затем `BOT PLAY`.
`BOT STATUS` показывает режим и число событий.
Для продолжения сохранённой записи выбери нужный слот (`BOT SLOT`), открой тот же уровень и нажми `CONTINUE`. Кнопка сама загружает сохранённый макрос из активного слота, включает Practice Mode, начинает уровень с начала, воспроизводит старые события и затем включает запись. Старые события сохраняются; во время Continue переключение слота блокируется, а `BOT STOP` автоматически сохраняет объединённый макрос. Если во время старого участка включён Auto-Retry, бот повторяет весь макрос с начала до достижения точки продолжения. При смерти во время добавочной записи Continue отбрасывает незавершённую добавленную часть и сохраняет старую запись, чтобы следующий Continue не повторял заведомо оборванный маршрут.
Файл макроса сохраняется в папку данных мода как `gdbot.gdm`.

Изменения v1.2.3 — полноценные вкладки и компактное меню
Главное окно переделано в четыре реально переключаемые вкладки: `PLAYER`, `GD BOT`, `VISUALS`, `SETTINGS`.
Функции разделены по категориям; смена вкладки не сбрасывает настройки.
Управление GD Bot собрано на отдельной странице: `REC`, `STOP`, `PLAY`, `CONTINUE`, `SAVE`, `LOAD`, `STATUS`, `LOOP`, выбор слота и скорость воспроизведения.
Настройки FPS, Auto-Retry, Hitboxes, CPS, Practice Music, Frame Step и чекпоинтов размещены в `SETTINGS`.
Визуальные переключатели и музыка меню перенесены непосредственно во вкладку `VISUALS`.
Окна Editor и Unlocks уменьшены и возвращаются в главное окно VETER.
Обновлены версия проекта и описание мода до `1.2.2`.
Проверка: ZIP/JSON и статические проверки исходника выполнены; сборку через Geode SDK и запуск в самой игре необходимо подтвердить в GitHub Actions/Geometry Dash.
