# VETER v1.2.9 — dark navy layout and single launcher

- Recolored the standard Popup background to navy and made the content panels opaque dark blue.
- Shifted navigation tabs and the three-column control area left; card widths now shrink to each available cell instead of forcing a too-wide minimum.
- Reduced tab/card height and tuned small-screen spacing.
- Fixed duplicated floating launchers: it is now attached only to the running scene, avoiding two overlapping touch delegates that could block dragging.
- Preserved feature callbacks, saved values, mod ID, and the v1.2.8 button resource.

This is a source archive for GitHub Actions, not a prebuilt `.geode`. Android compilation and in-game verification have not been run in this environment.
